Multi-boot e-reader installer

Install the boot selector, put firmwares into slots and back up your device. Needs a Chromium based desktop browser (Web Serial) and a USB cable.

Not connected

1. Install the boot selector

Writes the bootloader, the multi-boot partition table and the selector itself. This erases everything on the device, so take a backup first.

2. Install a firmware into a slot

The image is written exactly as released; only its name is stored separately.

3. Boot behaviour

4. Backup and restore

A backup is a raw 16 MB image of the whole flash, including your settings and books.
